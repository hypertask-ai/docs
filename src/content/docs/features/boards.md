title: Boards & Sections
description: Organize work with Kanban-style boards and customizable sections.
---

Boards are the primary workspace in Hypertask. Each board displays tasks in a Kanban-style layout with customizable sections.

## Creating a board

Boards belong to a project. Create one from the project dashboard or via the MCP tools.

## Sections

Sections are the columns on your board. Common setups include:

### Software development
- **Todo** - Planned work
- **Doing** - In progress
- **Review** - Awaiting review
- **Build** - Ready for deployment
- **Done** - Complete

### Simple workflow
- **Todo** - Not started
- **In Progress** - Being worked on
- **Done** - Finished

## Moving tasks

Tasks move between sections as they progress. This can be done via:
- Drag and drop in the web UI
- The `hypertask_section` MCP tool
- The `hypertask_update_task` MCP tool
