# Search Screen

The search screen provides a focused, keyboard-first way to find tasks across your board. It adopts a Superhuman-inspired design: a single aligned list of recent searches and tips, grey value completions (operator and values), and keyboard-driven workflows while deferring results until selection or Enter.

## Enhanced search preview: Owner+QA only

This enhanced search screen is a strict preview available to the Owner and QA roles. It is not a general release and does not require any minimum activity threshold. If you see the normal search UI, ensure you are on a checked board and the search preview flag is enabled for your account or team.

## Layout and structure

Top-level search shows a consistent list:

- **Recent searches**: A single list of your most recent searches.
- **Tips**: Helpful hints below recent searches (operator shortcuts, example queries).
- **AI panel**: Fixed on the right side, leaving the core search interface on the left.

No floating boxes. The suggestions list is full-width and aligned with the search box on desktop and mobile.

- **Mobile board tabs**: Under the search box, board tabs sit clearly above the bottom navigation, tapable with ample spacing and swipe-friendly when many boards exist.

- **Desktop**: Board tabs follow the same layout, for the same filter behavior across devices.

## Empty and loaded states

- **Empty search**: Recent searches (or none, if you have none) appear once, then tips below them. The AI panel stays fixed on the right side; the left side is free for search only.
- **Loaded search**: After selecting a suggestion or pressing <kbd>Enter</kbd>, aligned results appear under the suggestions list. Results do not start loading until you accept a suggestion or press <kbd>Enter</kbd>.

## Grey inline value completion

As you type, the inline suggestions box shows:

- **Top suggestion**: Completed in grey inside the list. Accept with <kbd>Tab</kbd>.
- **Operators**: Hinted inline (e.g., <code>lab</code> hints <code>el:</code>).
- **Values**: Top value preview in grey (e.g., <code>from:mal</code> shows <code>Malcolm Stern</code>).

This applies to common value types: people (names + emails), labels, boards. Results do not trigger while you type; they load only after you pick a suggestion or press <kbd>Enter</kbd>.

**Example**: Type <code>from:val</code>; the top suggestion <code>Valentin Yeo</code> appears in grey; select it with <kbd>Tab</kbd> to trigger a board fetch and show results.

## Tips panel

Under recent searches, tips explain operators the first time you open search:

- <kbd>Ctrl+K</kbd> / <kbd>Cmd+K</kbd> — open command palette.
- <code>from:</code>, <code>assignee:</code>, <code>in:</code>, <code>label:</code>, <code>is:</code>, <code>dates:</code>, <code>has:</code> — field modifiers.
- Press <kbd>Tab</kbd> on an inline value to accept it; choose Ask AI, operators, people, labels, or boards.

## Keyboard shortcuts (search UI)

- <kbd>Ctrl+K</kbd> / <kbd>Cmd+K</kbd> — open command palette.
- <kbd>Enter</kbd> — apply selected suggestion and load results.
- <kbd>Tab</kbd> — accept and grey the top inline suggestion and load results.
- <kbd>Shift+Tab</kbd> — previous suggestion.
- <kbd>Esc</kbd> — clear or dismiss panels.

## Sample workflows

1. Click the search box or press <kbd>/</kbd>. Empty state: recent searches and tips appear.
2. Type a partial term or operator (e.g., <code>from:mal</code>). Inline completion shows the top value in grey. Results do not load yet.
3. Select a suggestion with <kbd>Tab</kbd> (or hover & click). Results load under the suggestions list.
4. Press <kbd>Esc</kbd> to clear and return to the recents/tips layout; results are removed.
