This page covers personalization options at a glance: theme selection, dictation language settings, and AI model choices.

## Theme Selection

Hypertask provides a comprehensive theme system. Choose from five built-in themes or let the system match your operating system default.

### Available themes

| Theme | Description |
|-------|-------------|
| **Light** | Clean, minimal workspace with light backgrounds and subtle shadows |
| **Dark** | High-contrast dark mode for reduced eye strain in low-light environments |
| **System** | Automatically follows your operating system's preference (Light ↔ Dark) |
| **AMOLED** | Pure black backgrounds for OLED and AMOLED displays to conserve battery |
| **Paper** | Warm editorial light theme with soft paper-like backgrounds for a cozy writing feel |
| **Mobile** | Mobile-specific dark theme with touch-optimized controls (390x844+ viewport) |

### Viewing theme options

To see current theme and switch:

1. Open the **Teams** section
2. Click the gear icon next to the team name (then click **Users** or select a user)
3. Under **Appearance**, click the theme picker
4. Select a theme from the dropdown

Themes persist per user and apply globally across the app (board views, inbox, calendar, etc.).

<Aside type="tip">
Use the **board palette** (<kbd>Ctrl+B</kbd> / <kbd>Cmd+B</kbd>) to quickly switch accounts and view profile settings without leaving the board surface.
</Aside>

## Mobile UI

On mobile devices (~390x844 viewport), the app displays a notification indicator called the **rocket** in the rail.

### Rocket visibility

- The rocket appears when there are new updates to display
- On mobile, the rocket group clears the bottom tab bar to ensure visibility
- Users can open **Settings** to see the full list of updates when the rocket is hidden
- If there are no new updates, the rocket hides entirely and the X row in Settings shows additional options

### Settings behavior

Press <strong class="highlight">Settings</strong> to view your recent activity. When updates are pending, a rocket icon in the rail allows quick access. Once you've reviewed updates, settings shows a compact list and the rocket clears from the rail.

## Dictation Language Setting

Dictation language is now per-user. This lets you choose the language you prefer for voice-to-text input.

### Setting dictation language

1. Go to **Profile & Settings** (gear icon on user account row in sidebar)
2. Navigate to **Appearance** → **Dictation**
3. Select your preferred language (default is English)
4. Additional languages appear in the dropdown once configured

### Subsequent use

From then on, dictation uses the language you've selected. The setting is saved server-side and applies whenever you activate voice dictation in the task composer, reply box, or comment composer.

### Visibility notes

- The dictation language setting is **global** (per user) and affects dictation everywhere in the app
- Language packages and models are optimized for the selected language to improve accuracy
- You can change this setting at any time in settings

## AI Model Selection

AI models are configured globally in the team settings. The current model choice affects:
- Task Writer (`/task` command)
- Write with AI (`/ai` command and Write with AI button)
- Chat responses

### Available models

| Model | Best for |
|-------|----------|
| **Grok-4.1** | Fast responses, casual tone (RTX 5090 pricing model) |
| **Claude Opus-5** | High-accuracy reasoning and structured outputs |
| **Claude Opus-4.8** — legacy | Older model, deprecated (replaced by Opus-5) |
| **OpenAI** — removed | No longer supported; use local or custom providers |

### Changing AI models

1. Open **Teams** section
2. Click the gear icon next to the team name (then click **AI Models** or **General**)
3. Under **AI Models**, use the model picker dropdown
4. Select the model you want to use

### Model-specific notes

- **Grok-4.1**: Uses a new pricing model (RTX 5090) and offers faster response times
- **Opus-5**: Next-generation model with improved reasoning and structured output handling
- Legacy models continue to work for existing projects but are not shown in the picker

## Personalization Summary

| Setting | Location | Scope |
|---------|----------|-------|
| **Theme** | Profile & Settings → Appearance → Theme | Per-user, global |
| **Dictation language** | Profile & Settings → Appearance → Dictation | Per-user, global |
| **AI model** | Teams → AI Models picker | Team-wide, global |
| **Mobile rocket** | Rail (signals new updates) | Per-user activity stream |

These settings are saved server-side and apply across devices logged into the same account. You can change them at any time without losing your preferences.
