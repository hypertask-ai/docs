## Active quick-tips bar layout

- Board cards and lists hug the bottom of the quick-tips bar when that bar is on.
- Inbox visualizer surfaces flow and love states are pinned at the bottom.
- If you turn off the quick-tips bar, the remaining content fills the viewport.

## Closed quick-tips bar layout

- Board columns now run to the full height of their containers.
- Columns shrink by the measured height of the quick-tips bar when you re-enable it.

## Compact sidebar

- Left sidebar appears collapsed by default with a chevron toggle.
- Expand to 130px and show a logged-in user label.
- Toggle or viewing persistent state; tooltips reveal all real keyboard shortcuts including [<kbd>&#92;</kbd>] for the rail.

## Themes

Hypertask supports these themes; themeships with AMOLED v2 and two new themes:

- **AMOLED v2**: near-black elevation ladder, IBM Plex system typeface, compact card styling, muted ticket IDs on boards, and iris accent across core themes.
- **Dark Grey (New)**: refined accents, dark grey panel instead of white.
- **Light (New)**: light input well, white panel.
- **Graphite**: original Graphite theme.
- **Porcelain**: original Porcelain theme.

The system defaults are now Graphite/Porcelain (original Graphite left sidebar outline dropped). AMOLED v2, Dark Grey, and Light ship with refined typography and note minor visual polish in changelog entries.

For theme configuration and per-theme AI model selection, see [Profile & Settings](../getting-started/settings-profile.mdx).

## AI status updates

AI status updates appear on task cards when an AI agent has updated task metadata in a way you can see at a glance.
