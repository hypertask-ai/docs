Hypertask lets you control how things look and how AI behaves. Choose from multiple core themes, wave on mobile, customise the sidebar, keyboards, and dictation languages, and tailor AI options across tasks, boards, and help-site chat.

## Themes

Hypertask offers several built-in themes to suit your visual preference. All themes respect system fonts and support theming of emoji icons and modals.

### Light and Dark theme style

Light theme and Dark theme now map directly to porcelain and graphite visual styles:

- **Light theme**: porcelain-based panel backgrounds, borders, and accent colors (formerly Light (New))
- **Dark theme**: graphite-based panel backgrounds, borders, and accent colors (formerly Dark Grey (New))

This makes the theme names clear and consistent across features and components.

### AMOLED theme controls

The AMOLED theme v2 deploys with:

- IBM Plex as system typeface on light and dark routes.
- True-black expansion ladder of #101010 for cards.
- Compact card styling for dense information.
- Muted ticket IDs on board cards in AMOLED.

### Guest and replace rail themes

Guest demo boards and the expanded sidebar rail use the inverse theme for visual consistency, ensuring labels and controls stay legible even when the base theme is light or dark.

### Where themes apply

Themes in Hypertask apply across:

- Board and column backgrounds
- Task and comment surface colors
- Chart and graph surfaces
- Modals and dropdowns
- AI chat input and model selector
- Portrait rail icons and navigation labels

### Rich text and embedded content

Task descriptions and comments support rich HTML content, including video embeds. Hypertask's editor and API now preserve embeds from supported sources like YouTube, Loom, Vimeo, and Figma. When you add a video embed, it’s rendered directly in task cards and view summaries, and the embedded content is retained across API reads and writes. This makes it easier to keep context about recordings, demos, and design specs without manually linking to external sites.
