Your Appearance settings let you control the visual look of Hypertask and choose which AI models power built-in features like Task Writer and HyperAI.

---

## Themes

Hypertask offers three theme options:

- **Light** — Clean, light interface for environments with ample natural light.
- **Dark** — Easy on the eyes in low-light or evening sessions.
- **System** — Automatically follows your device’s night mode preferences.

To change your theme:

1. Open Profile → Appearance.
2. Select the desired theme from the Theme dropdown.
3. Refresh your view for full consistency across all boards.

<Aside type="info">
Dark mode is the default for new users and reduces eye strain during long work sessions.
</Aside>

## AI Model Selection

You can configure which AI model to use for Hypertask’s automation features:

### Available Models

| Model | Best for |
|-------|----------|
| **Default** | Balanced performance with low latency for general-purpose tasks. |
| **Fast** (GPT‑5.5 Fast) | Quick responses when speed matters, at the cost of slightly less detailed output. |
| **GPT‑5.5** | Balanced intelligence with strong reasoning—ideal for complex tasks. |
| **Claude 4** | Higher-quality creative and narrative tasks. |
| **Claude Haiku** | Low-latency drafting and summarization. |
| **Claude Opus** | Deep reasoning and complex planning—best for large projects with many steps. |

### Select a Default Model

1. Open Profile → Appearance.
2. Under AI Model, choose from the list of available models.
3. This model will power Task Writer and HyperAI by default.

<Aside type="tip">
You can still override the model per task in the Task Writer (e.g., "Write with Fast model") if needed.
</Aside>

## Preferences & Shortcuts

### Show Task Scroll

Enable this to have Hypertask automatically scroll to the full task description and comments when opening a task. Use it for long-form descriptions or detailed comment threads.

### Subtask Depth

Adjust how many levels of subtasks are drawn as parents by default. Guides the visibility of parent/child relationships at a glance.

### Expand Inline Details

Show rich fields like due date, assignee, labels, and more directly on task cards for quick scanning. Toggle off for a cleaner card view.

## Keyboard Shortcuts

Directly jump to these settings from anywhere in the app:

| Shortcut | Action |
|----------|--------|
| Ctrl+K → type "Appearance" | Open Appearance settings tab |
| Ctrl+K → type "Model" | Jump to AI model selection |
| Ctrl+K → type "Themes" | Jump to Theme dropdown |
