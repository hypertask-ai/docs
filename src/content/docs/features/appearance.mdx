## Theme defaults

Hypertask uses sensible theme defaults that adapt to your system settings while preserving control.

- **AMOLED** — the default dark theme (pure #101010 panel base, durable).
- **Light (New)** — the default light theme (refined light surface).
- **Legacy themes** — Dark Grey (New), Graphite, and Porcelain remain selectable from the Theme picker.
- **System behavior** — When a OS theme is detected, the app resolves the system default to AMOLED (dark) or Light (New) (light). Dark/Light, AMOLED ↔ Light toggles override those defaults; other theme pickers stay available.

## Visual system

### Typography

Typefaces are consistent across core themes. AMOLED adopts IBM Plex as the system typeface. Light (New) and legacy themes keep their existing core typefaces.

### Sidebar & modals

Modals use compact modal header sizing (48px/16px header, 44px/14px input, 36px/13px rows by default) for a contemporary feel. Legacy sizing remains opt-in.

### Homepage styling

Homepage elements now match the login/pricing design language for visual harmony; the hero features a product animation (16s crossfade of four real captured screens) with a static variant for reduced-motion users.

### Visual emphasis

Table column edges on AMOLED displays show a 2px purple accent line on hover and a full-height guide line while dragging; hovering any column header reveals faint column separators for better discoverability of the grid.
