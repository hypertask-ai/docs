Create, assign, and manage tasks across Kanban boards with a rich set of fields, priorities, relations, and subtasks. Tasks can have due dates, estimates, labels, attachments, comments, and relationships to other tasks.

---

## Get Started

Create a new task on any board:

1. Open a board.
2. Click the **Add task** button.
3. Enter a title and optionally a description.
4. Set priority, due date, labels, and assignee.
5. Click **Create** to add the task to the board.

<Aside type="tip">
Use `Ctrl+K` and search for "Add task" to open the quick-add task input from anywhere in the app.
</Aside>

---

## Main Task Regions

Each task contains several key areas:

- **Basic fields** — Title, description, priority, due date, estimate, labels, assignee.
- **Comments list** — Thread including each comment with author, timestamp, and full text.
- **Attachments** — File uploads and URLs linked to the task.
- **Subtask tree** — Parent/child relationships shown directly on the task page.

You can navigate to any task by `Ctrl+K` and searching for its ticket number (e.g. `HTPR-1234`).

---

## Task Page Config

Manage how tasks appear and behave using Profile > Task page settings:

- **Inline details** — Show due date, assignee, labels, attachments on task cards.
- **Task scroll** — Automatically scroll to full description and comments when opening a task.
- **Subtask depth** — Adjust how many levels of subtasks are expanded by default.

These settings apply to the task detail view and the task editor across all boards.

## Snooze and Navigation

Use the pushpin icon on any task to snooze it. When you snooze a task, the system automatically navigates your flow intelligently:

- **Next task in the current flow** — If you're browsing tasks in a continuous flow (for example, moving from one board to another), snoozing jumps to the next task in that sequence.
- **Back to previous context** — If there's no following task, snooze returns you to where you came from (such as the board or inbox that brought you to the task).

This behavior works consistently across desktop and mobile, including when you open a task directly from a browser or via shortcuts.

## Table View

Table view displays tasks in a spreadsheet-like layout with columns for title, priority, assignee, due date, and more.

### View options

- **Row height** — Adjust how compact each row appears to fit more or less information on screen.
- **Inline expansion** — Expand task cards to show a preview of the description and comments directly in the row.
- **Smart truncation toggle** — Control whether long titles truncate or wrap:
  - **Word wrap** (enabled by default): Titles break onto multiple lines so the full text remains readable at smaller screen sizes.
  - **Truncate instead**: Long titles are cut off with ellipses (...) and revealed by clicking or expanding.

Use the **Ctrl+K** command palette to quickly toggle title wrap mode from any board:

1. Press `Ctrl+K` to open the command palette.
2. Search for **"Toggle title wrap"**.
3. Select **Table view** and choose **Wrap** or **Truncate**.

The toggle is persisted per user, so your preference automatically applies whenever you open Table view.

## Task Row Indicators

Task rows display unread and pinned indicators. The display is simplified to avoid visual clutter:

- **Single dot** — When a task is both unread and pinned, only one dot appears. The blue unread indicator takes precedence over the yellow pinned indicator, placing the dot on the left side of the row (Standard) or right side (Compact) depending on your view settings.
- **Two dots** — A task that is unread **or** pinned shows two separate dots: blue for unread, yellow for pinned.
- **No dots** — A task's status is read and not pinned.

## Move Tasks to Inbox

You can move tasks directly to your inbox from the task detail page or via command palette:

- Open a task and use the **Move to inbox** action (or `Ctrl+K` then type "move task to inbox").
- From the list and Kanban views, drag the task to the Inbox section or use the **Move to inbox** command.
- The task is marked as unread and appears in your Inbox & Notifications page as a high-priority item.

---

## Subtasks

Create subtasks to break down complex tasks:

1. On a task detail page, click **Add subtask**.
2. Add one or more subtasks as needed.
3. Their parent-child relationships display automatically.
4. Mark subtasks complete by moving them to the parent task's Done section.

Use the Subtask depth control in Profile > Appearance > Task page to adjust visibility by default.

---

## Task Management

### Move Tasks

Drag-and-drop or select a new section to change a task's column.

### Reorder Tasks

Use the sort menu (or `Shift+S`) to order tasks by priority, due date, or last updated.

### Archive or Delete

Archive completed tasks. Deleted tasks are permanently removed after a grace period.

---

## Task Relationships

Tasks can reference other tasks:

- **Parent relationship** — Link a task as a subtask of another.
- **Linked task references** — Mentions in descriptions link related work.
- **Dependencies** — Mark dependencies so dependent tasks can't start until blocking tasks complete.
- **Block/blocked-by relations** — Mark tasks as blocking others or blocked by another task.
- **Duplicate relations** — Mark a task as a duplicate of another task (Linear parity).

### Block, blocked-by, and duplicate

Use the task detail page or `Ctrl+K` commands to set relationships:

- **Add related task** — Open a conversation to link this task to another.
- **Mark blocked by** — Set another task as the blocker for this task.
- **Mark as blocking** — Mark this task as a blocker for another.
- **Mark duplicate of** — Mark this task as a duplicate of another task.

These relations are visible from the task detail page in the Task Relationships section, and they help you visualize dependencies, blockers, and duplicates within your workflow.

## Keyboard Shortcuts

Jump to task actions quickly:

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` then type "Add task" | Open quick-add task input |
| `Ctrl+K` then type number | Jump directly to task HTPR-1234 |
| `Ctrl+O` | View all links in comments (even when comment composer is focused) |
| `Alt+1/2` (or other digit) | Jump to favorite board (global, including on board pages) |
