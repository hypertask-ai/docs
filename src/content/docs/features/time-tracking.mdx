<Steps>

<Step>Start a timer or log time manually</Step>

Use **`/time`** from the command palette to open the time tracking interface:

- **Timer mode**: Press <kbd>T</kbd> to start tracking time on the selected task (or press <kbd>Tab</kbd> to choose a target)
- **Manual entry**: Add a time entry by selecting a date, entering a duration (e.g., `2h 30m`), and optional note

Both modes support saving the entry directly from the form.

<Step>Use filters to view reports</Step>

The **`/time`** view aggregates time across your workspace and lets you filter by:

| Filter | Description |
|--------|-------------|
| **Team** | All users in your team |
| **Board** | Specific board or project scope |
| **User** | Individual user (use `?user=me` to see your own entries) |
| **Range** | Last 7 days, month-to-date, or custom date picker |
| **Group** | By task, board, user, or date |

Filters are saved per prompt so you can quickly re-apply the same view.

<Step>View and export CSV reports</Step>

After applying filters, click **Export** to download a comma-separated values (CSV) file:

- Formatted for Excel and Google Sheets with decimal hours
- No injected formulas or formatting artifacts
- Includes task number, description, user, duration, date, and note

CSV export supports the same range and group filters as the table view.

</Steps>

### Prompt shortcuts

<Aside>
Use these prompt patterns when entering `!` time tracking mode:

<dl>
<dt><code>!time today</code></dt>
<dd>Entries for the current day</dd>
<dt><code>!time task = T-123</code></dt>
<dd>Entries on task T-123</dd>
<dt><code>!time board = Marketing</code></dt>
<dd>Entries on the Marketing board</dd>
<dt><code>!time me last week</code></dt>
<dd>Your entries from the previous week</dd>
</dl>
</Aside>

### Quiet rows mode

Toggle **Quiet rows** in the view toolbar to hide the time cell for less verbose views. This keeps the table compact while preserving edit/delete access to each entry.

### Timer indicators

- **Running timer badge**: Appears in the Kanban header (Ctrl+K view) showing the number of active timers on the board
- **Per-board persistence**: Timer state is scoped per board — starting a timer on one board doesn't affect timers on other boards

<Steps style={{ marginTop: '1.5rem' }}>

<Step>Start a timer</Step>

1. Select a task on the board (or use `<kbd>Tab</kbd>` to pick one)
2. Press `<kbd>T</kbd>` — the timer starts automatically
3. Press `<kbd>T</kbd>` again to pause and save the entry

<Step>Refine filter views</Step>

1. Open `/time` from the command palette
2. Select filters from the Dropdown panel:
   - **Team**, **Board**, **User**, **Range**, **Group**
3. Click **Save filters** to prompt-saved states
4. Quickly re-open saved filters from the left panel

<Step>Export data</Step>

1. Apply filters you want to export
2. Click **Export CSV**
3. Open in Excel or Google Sheets — times display as decimal hours ready for calculations

</Steps>

<Aside>
<details>

<summary>Technical notes</summary>

- The `/time` interface includes an integrated header with no floating back button (consistent with settings-style pages)
- Report API supports query parameters: <code>?board={id}&amp;task={id}&amp;user=me&amp;running</code>
- Manual entries use integer and decimal hours for duration (e.g., <code>2h 30m = 2.5h</code>)
- Timer state is stored as <code>startTime</code> and <code>endTime</code> timestamps relative to the board scope

</details>
