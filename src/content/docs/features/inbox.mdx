The **Inbox** gathers all notifications (mentions, assignments, and more) into a single feed, letting you process them efficiently. Use keyboard shortcuts for quick actions and keep important work at the top of your queue.

## Viewing the inbox

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> to open the command palette and search for **"Inbox"**, or go to the Inbox page from the sidebar. The inbox shows:
- **Unread notifications** from mentions, assignments, reactions, and follow updates
- **Actionable items** like tasks, notifications with dismiss options (undo, dismiss all, undo all), and confirmed operations (invites, feedback)
- **Important tasks**: rows marked with the **Important** label appear first, in priority order and timeline-sorted (newest first)

### Replying to notification emails

Reply directly to a task notification email to add your response as a comment on the task. Send the reply from the same email address as your Hypertask account so Hypertask can verify it and post it under your name.

The inbox can be grouped into multiple views:

<Aside type="tip">Use <kbd>Ctrl</kbd> + <kbd>F</kbd> from the Inbox to search across all notifications. This is scoped across boards for board-agnostic filtering.</Aside>

### Bulk archive

Select multiple notifications with mouse clicks or keyboard navigation. When you select rows, the selection count appears next to the archive and remind icons, and the archive action archives all selected notifications in one step:

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Select all** | <kbd>Ctrl</kbd> + <kbd>A</kbd> | Select all visible rows in the current view, mirroring page behavior |
| **Archive selected** | <kbd>Shift</kbd> + <kbd>E</kbd> | Archive all selected notifications |
| **Archive all** | <kbd>Ctrl</kbd> + <kbd>E</kbd> | Archive all notifications (opens confirmation if many) |

<Aside type="note"><kbd>Ctrl</kbd> + <kbd>A</kbd> selects all visible rows rather than every row in the inbox due to index limits - select specific subsets when the list is long.</Aside>

### Triage with AI chat

Ask AI chat to read your inbox. It reads up to 500 messages per page and can continue through the remaining pages without asking for confirmation.

Before archiving a batch, chat previews every affected ticket, including other messages it would clear on those tickets. Confirm once for that batch. If the batch changes, chat shows a fresh preview and asks again. Its reply names the tickets it cleared.

### Inbox filtering scope

New users in a board see notifications for private tasks, while users removed from a board no longer receive those notifications in their Inbox. To prevent a stale notification from reappearing, you can reply to it (or tap Undo) to remove it from your queue. Cleaning up unsubscribed notifications helps keep the Inbox focused and relevant.

## Agent chatter in the inbox

<span class="label label--brand">Improvement</span> Agent messages from the AI now stay out of the personal inbox. Agent-only comments (FYI messages) and agent chatter no longer appear as notifications for human users. Instead:
- **Agent chatter ignored** – Pure agent commentary without a human @mention does not reach its owner's inbox.
- **FYI mentions visible** – An agent FYI comment with a human @mention does appear in the inbox, making it clear the human is being included in the loop, but it stays out of the Important section.
- **Only open questions land in Important** – When an agent poses a question that requires a human response, the message lands in the Important section so you can act on it first.

This applies to all agents using Hypertask's AI integration and keeps your inbox focused on questions and actions directly tied to your own work.

## Numbered pins in the mobile inbox

On mobile, each inbox row shows a numbered indicator next to the sender name. This creates a visual order that matches the date you received the notification, making it easier to scan recent items:
- **Numbered pins** appear on desktop and mobile inbox rows
- The numbers correspond to timeline order (newest first)
- This keeps your attention on the most recent important items without relying solely on the top position

<Aside type="tip">The numbered pins complement the timeline-sorted order for returning visits, giving you a quick visual guide to your recent notifications.</Aside>

## Invite link validation across pages

<span class="label label--brand">Improved</span> Pages that generate or use invite links now validate board context. **My Tasks** and **Inbox** no longer send invite-link requests without a board, which previously caused console errors. Requesting an invite link without a board now shows a clear message instead of a server error, keeping the console clean and providing explicit feedback when a board is required.

This change applies across most pages that send invite links, ensuring any invalid requests surface a user-friendly message rather than an unhandled error.

## Shortcuts tip visibility

<span class="label label--brand">Improved</span> When using the archive keyboard shortcuts (<kbd>Ctrl</kbd> + <kbd>E</kbd> or <kbd>Shift</kbd> + <kbd>E</kbd>), the tip that shows which shortcut to press (for example, "press E to archive") now appears and stays visible. The tip is tied to the bottom shortcut bar ("Ctrl+K for Command center, J to go down...").

Before this fix, repeatedly archiving would close the bottom shortcut bar or clear the inbox, causing the tip to disappear and making it hard to see which key shortcut to use. The tip is automatically disabled when the shortcut bar is hidden for the session, so navigating to the Inbox or re-opening the shortcut bar restores visibility.

## Board chip in the new task box

When you use <kbd>Ctrl+J</kbd> to create a new task from the inbox, the new task box shows a board chip indicating the intended destination:
- **Always visible**: The chip appears as soon as the box opens, so you always see the target board.
- **Same everywhere**: On a board or a ticket detail page, it shows that page's board.
- **Editable**: Click the chip to choose a different board before saving the task.

<Aside type="note">Ctrl+J uses the same board selection logic as the AI chat box: the focused ticket's board if there is one, otherwise the open board split, and finally the last used board for All or Important views.</Aside>
