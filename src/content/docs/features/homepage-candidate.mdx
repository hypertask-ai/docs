# Homepage Candidate

The **Homepage Candidate** provides an alternate landing experience at `hypertask.ai/home2.html`—a live, switchable version with new layouts, workflows, and faster keyboard navigation built into the candidate itself.

This is a separate, candidate homepage that coexists with the production homepage. You can view it directly and explore features in a fresh context without affecting the main site.

## Viewing the Candidate

Navigate directly to the homepage candidate URL:

```
https://hypertask.ai/home2.html
```

The candidate opens by default to a white (light) theme. The site automatically remembers your dark mode preference and will restore it until you explicitly change it.

## Theme Options

| Option | Appearance |
|--------|------------|
| **White (Light)** | Clean, high-contrast interface with white background and dark text. |
| **Dark** | Lower-light interface with dark background and light text. Automatically remembered between sessions. |

<Aside type="tip">
The homepage candidate uses the same account login as the main Hypertask app, so your preferences and state persist.
</Aside>

## Key Sections

The homepage candidate introduces several new sections and features:

### Keyboard Navigation Highlights

- Quick access to common actions via keyboard shortcuts
- Faster navigation between core areas of Hypertask
- Improved productivity for power users

### Quick Access Sections

The following sections are directly accessible from the candidate:

| Section | Purpose |
|---------|---------|
| **Views** | Switch between board views and filters instantly |
| **Inbox** | Open inbox and manage incoming notifications and tasks |
| **AI Agents** | Access agent-powered workflows and automation |
| **Skills & Power** | Explore advanced features and agent capabilities |
| **Proof & Pricing** | Review Proof of Work options and pricing plans |

## Full Feature Set

The homepage candidate showcases:

- **Optimized Layout**: Updated design for better information density
- **Reduced Load Time**: Slower entries closing in a brand new candidate pages, user feedback from internal usage.
- **Better Flow**: Refined UX for common tasks like checking alerts, switching views, and reviewing agents.
