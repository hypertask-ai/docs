# Agents Dashboard

The **Agents Dashboard** gives you a full-screen view of all your AI agents in Hypertask, organized by status. Instead of only viewing agents through modals, you now have a dedicated page at `/agents`.

## Navigate to the dashboard

- **URL**: `https://app.hypertask.ai/agents`
- From any page, use `Cmd+K` (Mac), `Ctrl+K` (Windows/Linux) and search for **"Go to Agents"** to jump there.

## View agents by status

The dashboard groups your agents into three top-level sections:

- **Running** — agents currently active and executing tasks
- **Quiet** — agents not currently running, but ready to start
- **Off** — agents paused or stopped

Each group displays agent cards that show key information at a glance.

## Agent cards

Each card in the dashboard shows:

- **Agent name** — the name of the agent
- **Current status** — Running, Quiet, or Off
- **On/Off toggle** — Immediate pause or resume of the agent
- **Heartbeat line for the merge/unblock timer**

The heartbeat line at the top of each agent card visualizes the status of the agent's 10-minute merge/unblock check:

- **Green dot, short bar** — the timer ran within the last 15 minutes
- **Amber dot, medium bar** — the timer ran between 15–30 minutes ago
- **Red dot, no bar or short red bar** — the timer missed its 10-minute window or has no data (missing data counts as down, never as fine)

This gives you a quick, color-coded view of whether each agent is operating within its expected runtime cadence.

## Card red outline for blocked agents

If an agent is blocke—meaning no one is actively working on it—the card displays a red outline to signal immediate action required. The blocked state is determined by an agent's configuration and its interaction with tasks on the board.

## Blocked-summary widget

A new widget next to the heartbeat line shows the count of agents currently blocke:

- **Red N** — the number of agents that are blocke and require someone to act

This gives you an aggregate view of unaddressed bottlenecks and helps prioritize follow-up work across your set of agents.

## Browse and filter agents

You can quickly scan through all your agents and filter by status sections. The dashboard scales to show all agents in your workspace, with cards laid out so you can easily compare running vs. paused agents.

## Performance and reliability

Agents are fully integrated with your board, tasks, and other AI tools. Use the dashboard to:

- See which agents are actively working
- Quickly pause or resume agents that are consuming resources
- Monitor agent distribution across your workflows
- Spot delayed or missed merge/unblock checks via the heartbeat line
- Identify agents that need human intervention via red outlines and the blocked-summary widget

## Working with pages and task detail pages

Agents can interact with task detail pages such as `/detail/project-15/<ticket>`. The production verifier validates these URLs, so agents can reference specific tasks from pages or create links to them. This makes it possible for agents to verify task lifecycles and generate pages as part of their workflows.

For more on agent setup and MCP configuration, see the [AI Agents](./agents.mdx) reference.

## Troubleshooting

<Aside type="note">

If you don't see an agent in the dashboard, check that:
1. The agent is properly connected to an active board
2. The agent schedule has the necessary permissions
3. The agent is associated with your team and not restricted to a different scope

See the [AI Agents](./agents.mdx) and [Scheduling Agents](./scheduling.mdx) pages for detailed setup guidance.

</Aside>
