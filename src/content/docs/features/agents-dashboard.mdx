# Agents Dashboard

The **Agents Dashboard** gives you a central view of your agents, including summary statistics, per-agent details, and board-scoped dashboards.

## Access the Agents Dashboard

- **URL**: `https://app.hypertask.ai/agents`
- From any page, use `Cmd+K` (Mac), `Ctrl+K` (Windows/Linux) and search for **"Go to Agents"**.

## Agent list by status

The overview page (`/agents`) groups your agents into three top-level sections:

- **Running** — agents currently active and executing tasks.
- **Quiet** — agents not currently running, but ready to start.
- **Off** — agents paused or stopped.

Each group displays agent cards showing key information.

## Agent cards

Each agent card shows:

- **Agent name** — the agent identifier.
- **Status** — Running, Quiet, or Off.
- **On/Off toggle** — pause or resume the agent.
- **Heartbeat line** for the merge/unblock timer.
- **Avatar** — a generated robot icon for each agent.

### Heartbeat line

The heartbeat line visualizes the agent's 10-minute merge/unblock check:

- **Green dot, short bar** — timer ran within the last 15 minutes.
- **Amber dot, medium bar** — timer ran between 15–30 minutes ago.
- **Red dot, no bar** — timer missed its 10-minute window or no data available.

### Card outlines

A red outline signals a **blocked** agent — no one is actively working on it. This helps you spot bottlenecks at a glance.

### Blocked-summary widget

A blocked-summary widget shows the number of agents currently blocked, helping you prioritize follow-up work.

## Board-scoped agent pages

Each board has its own dedicated agent page showing the agents configured for that board:

- **URL format**: `https://app.hypertask.ai/agents/<board-number>`
- Example: Board 5500 is available at `https://app.hypertask.ai/agents/5500`.

The board page includes:

- Board-specific agent list.
- Toolkit bug totals, including AGTE tickets tagged as bug.
- Configuration source: board, repository, branch, and agent list read from a shared setup.
- Main merge counts or reference links for the board.

Use board pages to inspect board-level agent health and bug tracking per board.

## Performance and reliability

Use the agents page to:

- Spot which agents are actively working.
- Pause or resume agents consuming resources.
- Monitor agent distribution across workflows.
- Identify blocked agents via red outlines and the blocked-summary widget.

## MCP client evaluation frame

When the MCP client eval is enabled, the agents page displays a table of 20 real Hypertask tasks run through the MCP server and CLI. Each row shows pass/fail, token in/out, wall time, and tool call count. This helps you compare MCP to the CLI and catch regressions.

## Working with pages and task detail pages

Agents can reference task detail pages (e.g., `/detail/project-15/<ticket>`) via the production verifier, enabling them to verify lifecycles and create links as part of workflows.

## Troubleshooting

<Aside type="note">

If you don't see an agent in the dashboard, check that:

1. The agent is connected to an active board.
2. The agent schedule has necessary permissions.
3. The agent is associated with your team or scope.

See [AI Agents](./agents.mdx) and [Scheduling Agents](/mcp/scheduling.mdx) for setup details.

</Aside>
