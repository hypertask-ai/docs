AI is woven through every part of Hypertask — create tasks, filter your board, smart-label workloads, and manage daily operations without leaving the workflow you already use.

<Steps>

1. **AI-assisted task creation**
    - Click `AI` in the top-right corner of any board, open the `Ask Hypertask AI` panel, and describe a task in plain English.
    - AI parses the description and creates a task pre-assigned to you with a title, description, and relevant tags (task types, priorities, area).
    - Review the generated task before saving; edit fields or refine the prompt and generate again.

2. **Prompt-based filtering**
    - In the `Board Filter`, type natural-language constraints like:
        - `show me top-priority bugs`
        - `tasks assigned to Valentin and due this week`
    - Use combinations such as `high priority and not blocked`, and press `Enter` to apply.

3. **Smart labels**
    - Open a label (or the Manage Tags screen) and create a new label marked as a **smart label**.
    - In the "Smart label — AI keeps this label on matching tasks" field, define which tasks should carry it, for example:
        - `backend issue, involves DB, high impact`
    - Save; AI immediately classifies the board up to 500 existing tasks and adds the label to matches. Smart labels show a sparkle icon in label lists.
    - New tasks are classified when created; edited tasks are re-classified when title or description change; updating the prompt re-runs classification for the entire board.

4. **Batch-powered background workloads**
    - Background smart labels and other AI classification runs that involve many tasks are routed to Anthropic’s Batch API at half price, allowing cost-efficient processing at scale.
    - Matching tasks receive their labels automatically; activity is logged in the task activity feed.
    - You don’t see extra UI for this—it happens invisibly in the background with consistent results.

5. **Faster agent task lists**
    - AI agents are now much quicker to load their task lists, especially after server warm-up.
    - Previously slow database reads that fetched task lists have been optimized: the slowest 5% of calls improved from ~129 ms down to ~40 ms. The improvement consistently benefits agents on both warm and cold servers, making AI-driven workflows feel far more responsive.

6. **AI Chat histories**
    - Open AI Chat from the right rail or press `Ctrl/Cmd + I` to see a list of conversations.
    - In the full-screen chat view (desktop), the history list pages as the window resizes, and you scroll to load more older chats. Pick or filter from that list to open a chat.
    - On mobile, the list is limited; tap an entry to open its history.
    - The docked chat always shows your most recent chats inline; use the full-screen view for history navigation.

</Steps>

## Where AI appears

| Area | What AI does |
|------|--------------|
| **Task creation** | Parses your description into a task with title, description, priority, and tags. |
| **Board filtering** | Understands natural-language constraints and builds dynamic filters. |
| **Smart Labels** | Keeps labels on tasks that match your AI prompt; changes to tasks or the prompt trigger reclassification. |
| **AI Chat** | Global assistant for questions, summarization, and quick actions, with full-screen history paging. |
| **Bulk AI workloads** | Heavy classification runs use the Batch API to handle large boards efficiently; background jobs go through Anthropic’s half-price Batch endpoint. |
| **Agent task lists** | Optimized reads for quick agent workloads; significant speedup for the slowest dataset slices. |

## Settings

- Choose your preferred AI model in the **Appearance & AI Models** settings page. Different models may produce different responses.
- Adjust leniency of AI-assisted task creation in the same settings area if you prefer more precise or broader suggestions.
- Smart label accuracy can be tuned by sharpening or relaxing your prompt; see the "How it stays current" details in the Smart Labels reference.

<Aside type="note">

Smart labels and prompts are a best-effort AI signal. They do not substitute for human review. Ensure your prompt manages edge cases or exceptions directly, for example: "NOT: schema changes on branches not yet merged."

</Aside>

<Aside type="tip">

Use smart labels together with filters and saved views to create reusable patterns for recurring workloads (e.g., `on-call issues`, `quick fillers`, `enterprise integrations`).

</Aside>
