AI in Hypertask lives alongside your projects, not as a separate tool. Use natural language to create tasks, get suggestions across your work, and keep your information fresh and up-to-date.

## Quick Start

Use the AI assistant via:

- **Keyboard shortcut:** <kbd>Ctrl+K</kbd> then search for "Ask AI" or type slash and "ask"
- **In a comment:** Click the sparkle icon or use <kbd>Ctrl+J</kbd> to write with AI
- **On mobile task detail:** "Ask AI" sparkles up in the thumb-zone button bar

---

## Scope-aware chat context

AI chat maintains context-aware scope that adapts as you move between tasks and boards. The scope chip in the chat header displays the current context, including:

- **On a task:** Shows the ticket number (e.g. INNE-1491) with a task icon and the full task title on hover
- **On a board:** Shows the board name and icon
- **Scroll and board awareness:** Changing views or scrolling between sections doesn't reset the chat context; the AI thread follows your work seamlessly across the board

The scope picker allows precise control:

- **Current board (default):** Automatically adapts to navigation, with per-board tagging
- **Pinned board:** Locks context to a specific board and prevents scope auto-swap
- **All boards:** Applies to everything with per-board counts, plus a "No" bucket for legacy chats

## Skill invocations in AI chat

In AI chat and in the AI Task Writer, start any message with `/skill <skill>` to invoke a skill. For example:

- `/minimalist-review` previews a task in Minimalist style
- `/wit-review` adjusts tone and framing

After the skill executes, you can compose or refine the prompt. The invocation always produces board-aware outputs that respect your column, section, and current filter context.

---

## Popup positioning

Skill popups and slash-command menus anchor at the caret glyph, follow your text flow, and flip upward when near the viewport bottom so text never gets clipped. Keyboard navigation (Tab, Enter, Arrow keys, Escape) controls the popup; selecting a skill never submits the prompt.

---

## Skill invocations in comments

In comments, use <kbd>Ctrl+J</kbd> (keyboard) or the Sparkles icon (mouse) to write with AI. In AI chat, you can also take focused comments into the chat:

- **Copy comment to AI chat:** Focus a comment, press <kbd>Ctrl+K</kbd>, then select Copy comment to AI chat. The comment text flows into the chat draft as if you'd typed it.
- **Summarize comment:** Focus a comment, press <kbd>Ctrl+K</kbd>, then select Summarize comment. AI drafts a concise summary in the chat.

Hover over a comment to reveal the Sparkles cue for mouse users, making these commands available from any input device.

## Asking AI in Comments

Start a comment or a new message with a short prompt, e.g.:

- "Set priority high and assign to me"
- "Add @Alice to the assignee list"
- "Purge all tags"

After your request, AI will update the task's properties accordingly.

### Possible responses

- Priority, assignee, and tags updates
- Description edits — rewrite, summarize, or extend
- Link mentions — AI adds @mentions to project members
- Suggested next actions — AI proposes concrete follow-ups

To start over, click the refresh icon to propose a different rewrite.

## Mobile AI Integration (HTPR-4603)

On mobile task pages, the "Ask AI" burst scrolls into the thumb zone after the page loads. From here:

- Tap the sparkle to send the task ID + context to the AI assistant
- Slide down to return to the board
- Use Swipe-to-reveal actions to access further options

The setup keeps AI accessible without obscuring the task content and mirrors desktop interactions.

---

## Mobile Chat Behavior (HTPR-4601, HTPR-4602)

The mobile AI chat completes the board experience when you have access to task details from anywhere. Key behaviors:

**Exit and navigate** — The mobile chat closes when you tap a task link, follow a link in a comment, or use the back gesture. This keeps the chat surface unobtrusive while letting you jump to task details without losing context.

**Header visibility** — The chat header shows the close (X) button and back affordance, ensuring mobile users can always exit the chat screen. Tapping outside the chat or using the back gesture closes the chat and returns you to the board.

**Popup positioning** — Slash-command menus and skill popups anchor at the caret and flip upward when text is near the bottom so they never clip.

## Task Creation

Use Ctrl+K "Ask AI" to generate a task title and description in one go. AI uses your conversation context and past board content to produce relevant, scoped suggestions.

Example prompt:

```
Create a task for "Update the billing page footer" on project 15 with priority high
```

AI proposes a resulting task with title, description bundle (phase asks), priority, and due date. Author it if the proposal fits, or refine with follow-up.

**Slash commands in Task Writer**

In the AI Task Writer you can also invoke skills directly. Start your message with `/skill` followed by the skill name, then let the skill draft the content before you edit.

---

## Task Enhancement

Ask AI to expand or prune descriptions:

- "Make this task more detailed for a new hire"
- "Summarize this task into a checklist" — produces checkboxes
- "Turn this into a bug template" — adds reproduction steps
- "Trim to the core deliverable" — shortens

AI can turn any comment, task description, or stand-up update into a task and vice versa.

---

## Voice Dictation

Start voice on any text field with <kbd>Ctrl+Shift+N</kbd> or the microphone icon in the compose bar.

See [Keyboard Shortcuts](/features/keyboard-shortcuts/) for Mac/Windows note.

## Keeping Content Fresh

Use "AI rewrite" on comments or task descriptions to:

- Improve readability
- Shorten for mobile or notes
- Write follow-ups or next steps
- Surface action items with checkboxes

"Next stuff" bullets in Tiptap editors suggest actions.

---

## Command Palette AI Panel

Ctrl+K opens the panel. Adding `/ai` to a query means "respond using AI":

- "/ai reorganize my inbox" — AI sorts entries by importance
- "/ai generate a concise board summary" — AI overviews tasks and sections
