This page lists every keyboard shortcut registered in Hypertask for Windows/Linux and Mac.

<Aside type="note" title="App-shell rail">
The **App shell surfaces** shortcuts <kbd>1</kbd> through <kbd>6</kbd> apply only when the app-shell rail is enabled.
</Aside>

<Aside type="note" title="Mac board switching">
On Mac, switch boards with <kbd>Ctrl</kbd> + <kbd>0-9</kbd>, not <kbd>Cmd</kbd> + <kbd>0-9</kbd>. Mac browsers reserve <kbd>Cmd</kbd> + <kbd>1-9</kbd> for tab switching.
</Aside>

<Aside type="note" title="Mac command palette">
On Mac, <kbd>Ctrl</kbd> + <kbd>K</kbd> opens the command palette in addition to <kbd>Cmd</kbd> + <kbd>K</kbd>.
</Aside>

## Hiding and Showing Columns

To hide a column using the Command Palette:

1. Open the Command Palette: <kbd>Ctrl</kbd> + <kbd>K</kbd>
2. Type "hide" to find the "Hide column" action
3. Press <kbd>Enter</kbd> to hide the active (hovered/last-clicked) column directly
4. The Command Palette closes automatically after execution

To show previously hidden columns:

1. Open the Command Palette: <kbd>Ctrl</kbd> + <kbd>K</kbd>
2. Type "show" to find the "Show columns" action
3. Press <kbd>Enter</kbd> to reveal all hidden sections

<Aside type="note">
"Hide column" now targets the last clicked or currently hovered section rather than cycling through sections, making it easier to hide the specific column you're working with. The "Empty columns" command also reads the current state and filters both the Kanban view groups and the table view groups, showing "Show empty columns" when they're hidden and "Hide empty columns" when they're visible.
</Aside>

## Board palette (HTPR-4522)

Press <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) or <kbd>Cmd</kbd> + <kbd>B</kbd> (Mac) to show the board palette overlay. On the left rail, the board palette displays your user account row with:

- **Email or handle** — Click to open the account switcher dialog
- **Avatar** — Click to open Account & Profile settings

This provides quick access to switching workspaces or reviewing your account configuration without leaving the current board.

<Aside type="tip">
The board palette joins <kbd>Ctrl+K</kbd> as a non-intrusive way to access workspace settings while staying in context.
</Aside>

## Open Latest Updates (HTPR-4813)

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (Windows/Linux) or <kbd>Cmd</kbd> + <kbd>K</kbd> (Mac) then search for **"Latest Updates"** in the board palette or command palette to open the Latest Updates panel from any route in the app. This provides quick access to see recent activity across your boards without leaving your current view.

## Global Alt+Number shortcuts (HTPR-5126)

The global Alt+Number shortcuts <kbd>Alt</kbd> + <kbd>1-7</kbd> switch to the corresponding app-shell rail surface when the rail is enabled (Board = 2, Table = 3, etc.). When not using the rail, the rail surfaces are not available to map to. This mapping now persists correctly and is properly supported on all views when the rail is active.

## Timer shortcuts (HTPR-4414)

Time tracking shortcuts are available when time tracking is enabled for your board or task:

- **App shell rail** — Press <kbd>7</kbd> on the rail to open the running-timers view
- **Task detail** — Press <kbd>Option</kbd> + <kbd>T</kbd> or <kbd>Alt+T</kbd> to start or stop the open task timer

The timer indicator appears in the task card and task detail, showing whether a timer is running for that task.

See the <a href="/features/time-tracking/">Time Tracking</a> page for full details.
