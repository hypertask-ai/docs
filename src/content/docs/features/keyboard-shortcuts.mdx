This page lists every keyboard shortcut registered in Hypertask for Windows/Linux and Mac.

<Aside type="note" title="App-shell rail">
The **App shell surfaces** shortcuts <kbd>1</kbd> through <kbd>6</kbd> apply only when the app-shell rail is enabled.
</Aside>

<Aside type="note" title="Mac board switching">
On Mac, switch boards with <kbd>Ctrl</kbd> + <kbd>0-9</kbd>, not <kbd>Cmd</kbd> + <kbd>0-9</kbd>. Mac browsers reserve <kbd>Cmd</kbd> + <kbd>1-9</kbd> for tab switching.
</Aside>

<Aside type="note" title="Mac command palette">
On Mac, <kbd>Ctrl</kbd> + <kbd>K</kbd> opens the command palette in addition to <kbd>Cmd</kbd> + <kbd>K</kbd>.
</Aside>

## Mobile comment composer gesture actions

On mobile devices, the comment composer keeps dictation as the primary input method with simplified controls:

- Dictate first, then refine with the *Improve with AI* option (opens a focused bottom sheet on mobile)
- Send remains the secondary, accessible action
- The Improve with AI trigger provides inline text enhancement without replacing dictation as the primary entry point

<Aside type="tip">
On mobile, start with dictation and tap *Improve with AI* to refine your comments without leaving the input flow.
</Aside>

## Mobile in-app gestures

- On mobile, a one-finger swipe left or right on a comment opens its quick actions menu with Edit, Delete, Star, and Pin options

## Image & Media

|--------|---------------|-----|

| Insert GIF into comment | <kbd>Enter</kbd> | <kbd>Enter</kbd> |

<Aside type="tip">
The GIF picker is a picker component you navigate with keyboard. Type <kbd>/</kbd> in the comment or description compose box, search for "giphy", then use arrow keys to move the highlight, Tab to switch 10x10 tabs, and Enter to insert the selected GIF.
</Aside>

## Hiding and Showing Columns

To hide a column using the Command Palette:

1. Open the Command Palette: <kbd>Ctrl</kbd> + <kbd>K</kbd>
2. Type "hide" to find the "Hide column" action
3. Press <kbd>Enter</kbd> to hide the active (hovered/last-clicked) column directly
4. The Command Palette closes automatically after execution

To show previously hidden columns:

1. Open the Command Palette: <kbd>Ctrl</kbd> + <kbd>K</kbd>
2. Type "show" to find the "Show columns" action
3. Press <kbd>Enter</kbd> to reveal all hidden sections

<Aside type="note">
"Hide column" now targets the last clicked or currently hovered section rather than cycling through sections, making it easier to hide the specific column you're working with. The "Empty columns" command also reads the current state and filters both the Kanban view groups and the table view groups, showing "Show empty columns" when they're hidden and "Hide empty columns" when they're visible.
</Aside>

## Global Alt+Number board shortcuts (HTPR-5126)

**Before:** On the table view or any board view, <kbd>Alt</kbd> + <kbd>1-7</kbd> shortcuts did nothing even when the app-shell rail was supposed to be active, causing them to behave as no-ops.

**After:** When the rail is enabled, <kbd>Alt</kbd> + <kbd>2-7</kbd> now correctly switch to their corresponding surfaces (Board = 2, Table = 3, Calendar = 4, AI Chat dock = 5, and Search = 6) from any view. On Mac, the global board switcher uses <kbd>Ctrl</kbd> + <kbd>2-7</kbd> instead of <kbd>Cmd</kbd> to avoid interfering with tab switching.

<Aside type="note">

</Aside>
