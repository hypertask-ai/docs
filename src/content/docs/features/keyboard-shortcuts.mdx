This page lists every keyboard shortcut registered in Hypertask for Windows/Linux and Mac.

<Aside type="note" title="App-shell rail">
The **App shell surfaces** shortcuts <kbd>1</kbd> through <kbd>6</kbd> apply only when the app-shell rail is enabled.
</Aside>

<Aside type="note" title="Mac board switching">
On Mac, switch boards with <kbd>Ctrl</kbd> + <kbd>0-9</kbd>, not <kbd>Cmd</kbd> + <kbd>0-9</kbd>. Mac browsers reserve <kbd>Cmd</kbd> + <kbd>1-9</kbd> for tab switching.
</Aside>

<Aside type="note" title="Mac command palette">
On Mac, <kbd>Ctrl</kbd> + <kbd>K</kbd> opens the command palette in addition to <kbd>Cmd</kbd> + <kbd>K</kbd>.
</Aside>
