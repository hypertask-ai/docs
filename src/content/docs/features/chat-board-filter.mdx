Use the board filter in AI Chat to quickly focus on chats from one board, or view all chats across your boards. Set a default to start side by side.

## Board filter behavior

- <strong>All boards</strong> — shows every chat across all your accessible boards.
- <strong>One board</strong> — shows only chats from that board.
- Default is <strong>All boards</strong>, so all your chats appear by default when you open the chat.

<Aside type="tip">
Run /chat or switch to the Chat view to start a conversation. Then use the board filter above the chat list to switch between "All boards" and a specific board.
</Aside>
