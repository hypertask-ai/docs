  --project <id>

  --attach <path-or-url>

  --improve
      Run the text through the AI writer before posting (default: improve-readability)
  --improve-command <name>
      Which AI rewrite to run with --improve: improve-readability (default), fix-spelling, summarize, make-shorter, or translate:<language>
