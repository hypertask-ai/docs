## July 16, 2026

### New Features

- **Enhanced AI chat sessions with improved continuity** — AI chat maintains conversation history across sessions, so you can return to previous discussions without losing context. ([HTPR-3197](https://app.hypertask.ai/detail/project-15/3197))
- **Improved AI Task Writer formatting** — AI-generated task descriptions now render with consistent formatting, including correct tag placement and structure. ([HTPR-1789](https://app.hypertask.ai/detail/project-15/1789))
- **Task Writer support on mobile devices** — AI Task Writer is now accessible on mobile, featuring a streamlined interface optimized for touch input. ([HTPR-1952](https://app.hypertask.ai/detail/project-15/1952))

### Bug Fixes

- **Enhanced security for section API endpoints** — The `/api/section/update` endpoint now includes ownership validation to prevent unauthorized section modifications. Previously, an IDOR vulnerability allowed any authenticated user to modify sections across projects. Verified live on production. ([HTPR-3197](https://app.hypertask.ai/detail/project-15/3197))
