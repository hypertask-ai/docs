## July 14, 2026

**New Features**

- **Manage Tags: bulk-select and delete labels** — The Manage Tags panel now supports bulk deletion. Select multiple labels at once using the checkboxes next to each row, or use **Select all** to tick every label in the current search filter. A footer appears showing the count, and **Delete N tags** opens a confirmation modal warning that deletion is permanent before removing all selected labels in one action. See the [Tasks docs](/features/tasks/) for details. ([HTPR-4241](https://app.hypertask.ai/detail/project-15/4241))

- **Beta app layout: left icon rail with splits-style header** — A redesigned app shell is available as an opt-in beta. Press <kbd>Ctrl+K</kbd> and search for **"New layout: left icon rail (beta)"** to toggle it on (default OFF). The new layout replaces the top icon bar with a fixed 48 px left rail: Inbox (with unread badge) and AI Chat on top, board/table/calendar surface switchers in the middle, and avatars, invite, theme toggle, and settings at the bottom. Every surface uses a splits-style header with a home icon for the primary view and inline search/filter controls. It's a pure repositioning of existing icons and actions — no functionality is lost. See the [What is Hypertask? docs](/getting-started/introduction/) for details. ([HTPR-4201](https://app.hypertask.ai/detail/project-15/4201))

- **AI Usage cost-attribution report in Settings** — The **Settings → AI Usage** page now shows a first-party cost-attribution breakdown powered by the AI Gateway's internal metering table (AiUsage). Usage is broken down **By Feature** (AI Chat, Task Writer, Text Enhancement, etc.), **By Model** (Claude Sonnet 5, GPT-5.5, etc.), and **Top Users** — so workspace owners and admins can see exactly where AI spending goes. Access has been widened from owner-only to **owner or admin**. The breakdown degrades gracefully (hidden) if the underlying usage table is unavailable. See the [AI Features docs](/features/ai-features/) for details. ([HTPR-4136](https://app.hypertask.ai/detail/project-15/4136))

**Improvements**

- **AI Chat: animated thinking dots while waiting for a response** — When you send a message in AI Chat, animated thinking dots now appear immediately in a new assistant bubble, giving you instant visual confirmation that the AI is processing your request. The dots clear automatically as soon as the first token of the response arrives. See the [AI Features docs](/features/ai-features/) for details. ([HTPR-4235](https://app.hypertask.ai/detail/project-15/4235))

- **Inbox task detail: archive checkmark alongside remove-notification icon** — When you open an inbox task, the task detail header now shows both the remove-notification icon and an archive checkmark side by side, so you can dismiss or archive the notification without leaving the task detail view. See the [Inbox & Notifications docs](/features/inbox/) for details. ([HTPR-4240](https://app.hypertask.ai/detail/project-15/4240))

- **Manage Tags: autofocus search, per-tag ticket counts, and filter-board link** — The Manage Tags panel now autofocuses the search input when opened, so you can start typing immediately to filter labels by name. Each tag displays a live per-tag ticket count (e.g., "12 tickets · 5 archived"), counting active (Normal-status) and archived tasks separately so you can see how widely each label is used. A filter icon next to each tag applies that label's filter to the board instantly — the command palette closes and the board switches to a filtered view showing all columns with matching tasks. See the [Tasks docs](/features/tasks/) for details. ([HTPR-4177](https://app.hypertask.ai/detail/project-15/4177))

- **Calendar view redesigned for the new app shell** — In the new shell layout, the calendar toolbar sits on the dark shell background with the date range and navigation chevrons left-aligned next to the sidebar hamburger and back arrow. The week grid renders inside a single grey rounded bordered card, giving the calendar a clean, contained appearance that matches the rest of the shell. See the [Boards & Sections docs](/features/boards/) for details. ([HTPR-4237](https://app.hypertask.ai/detail/project-15/4237))

**Bug Fixes**

- **Fixed: Ctrl+E as it does not advance to the next task** — Previously, pressing <kbd>Ctrl+E</kbd> on an inbox task would archive the notification and flip the task to Archive status, but then nothing would happen—the focus and view would not move to the next task. The navigation now completes correctly, so each <kbd>Ctrl+E</kbd> moves the workflow forward through your inbox. Verified on production with real-browser tests. ([HTPR-4234](https://app.hypertask.ai/detail/project-15/4234))

- **Fixed: Board header sidebar icon replaces in-pill chevron** — The board header now shows a dedicated panel-left sidebar icon to the left of the board name pill, replacing the chevron that was embedded inside the pill. Clicking the icon opens the board manager; clicking the board name still selects the home view. ([HTPR-4242](https://app.hypertask.ai/detail/project-15/4242))

- **GIFs and emoji in comments: GIF picker tab with /giphy and /emoji slash commands** — The comment composer now includes a built-in Emoji & GIFs picker with two tabs. Type `/emoji` to jump straight to the emoji library, or `/giphy` to open the GIFs tab powered by Giphy. Browse trending GIFs or search by keyword, then click to insert. Inserted GIFs render as resizable media — drag the corner handles to set the size, and the dimensions are preserved when the comment is posted. See the [Collaboration docs](/features/collaboration/) for details. ([HTPR-4232](https://app.hypertask.ai/detail/project-15/4232))

- **Fixed: AI agents can now self-assign tasks via MCP** — The MCP assign route previously only accepted a numeric `user_id`, preventing agents from adding themselves as assignees without knowing their own user ID. The `assign_self: true` parameter has been added to `hypertask_assign_user`, letting an authenticated agent token add the calling agent as an assignee directly. The existing `user_id` path is unaffected. See the [MCP Tools Reference](/api/tools-reference/) for details. ([HTPR-4141](https://app.hypertask.ai/detail/project-15/4141))

- **Fixed: Comment composer overflows when quoting with AI chat open in narrow column** — Previously, when you quoted a comment while the AI panel was open in a narrow column, the composer would stay at a capped small size and the text would overflow upward, making the Send toolbar unreadable. The composer now expands to fit its available width (380px measured) so the comment can be read and posted without scrolling. Blurred composers now scroll smoothly instead of spilling content off the screen. Verified on production with headless click-through testing. ([HTPR-4231](https://app.hypertask.ai/detail/project-15/4231))

- **Fixed: Dia theme: comment edit surface renders stark white** — Comments opened for editing in the Dia theme now render with neutral background colors instead of completely white surfaces, improving contrast and readability across themes. Verified visually in production. ([HTPR-4226](https://app.hypertask.ai/detail/project-15/4226))

- **Fixed: Board view deep links now switch to the correct view on open** — Sharing a URL like `https://app.hypertask.ai/project?id=15&view=bugs` now reliably switches the board to the named view as soon as the link is opened. Previously, the board would load but stay on whichever view was last active, requiring a manual switch. Using the browser Back button after following a deep link also works correctly — the board re-arms the view selection rather than silently ignoring the navigation. ([HTPR-3828](https://app.hypertask.ai/detail/project-15/3828))
