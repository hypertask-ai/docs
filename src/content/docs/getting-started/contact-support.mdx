---
title: Get help
description: How to contact support. Start with the AI help chat, which can hand off to the team in the same chat.
---

Start at the [AI help chat](https://help.hypertask.ai). It answers from these docs, and it can hand the conversation to the team in the same chat when it cannot solve something.

- Ask there first, including when you want to talk to a person.
- You can email [help@hypertask.ai](mailto:help@hypertask.ai). The [contact page](https://hypertask.ai/contact/) uses that address for support, partnership, and press.
- Signed in, open **Settings → Help → Send feedback**. That screen says it goes straight to the team. Mark it Bug, Idea, Question, or Praise.
- Free and BYOK list email support. Pro lists priority support.
- For privacy questions, the [privacy policy](https://hypertask.ai/privacy/) names Hypertask Lab Ltd. and links to the same contact page.
