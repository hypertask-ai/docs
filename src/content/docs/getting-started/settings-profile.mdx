Your Profile page is split into three dedicated sections: **General**, **Appearance**, and **Task page**. Each has its own navigation point and can be accessed directly via Ctrl+K.

---

## Profile Basics

The <strong>General</strong> tab contains identity-related settings:

- **Avatar** — Upload or change your profile picture.
- **Display name** — The name shown to others in tasks, comments, and activity feeds.
- **Email** — Your primary email address; used for notifications and logins.
- **Bio** (optional) — A short description shown in your profile card.

<Aside type="tip">
Ctrl+K to open the command palette and search for "Profile" to jump to each section quickly.
</Aside>

---

## Appearance

The <strong>Appearance</strong> tab controls how the interface looks:

- **Theme** — Choose between Light, Dark, or System theme (automatically follows OS preference).
- Font size — Adjust text size across the app for better readability.
- Reduced motion — Reduce animations for a calmer environment.

Use Appearance changes to match your lighting conditions or personal comfort preferences.

---

## Task Page

The <strong>Task page</strong> tab configures behavior specific to how tasks display:

- **Show task scroll** (on/off) — When enabled, automatically scroll to fit the entire task description and details when opening it.
- **Subtask depth** — Control how many levels of subtasks are visible by default.
- **Expand inline details** — Show fields like due date, assignee, and labels inline on the task card.

These settings apply to the task detail view and the task editor across all boards.

---

## Common Actions

### Change your avatar or name

1. Open your Profile page in the app.
2. Switch to the <strong>General</strong> tab.
3. Upload a new image or edit your name under the Avatar or Display name fields.
4. Click <strong>Save</strong> to apply changes.

### Change your theme

1. Go to your Profile page and open the <strong>Appearance</strong> tab.
2. Select **Light**, **Dark**, or **System**.
3. Switching applies immediately; close all open task modals to see the full change reflected across the UI.

### Change task page preferences

1. Open your Profile page and go to the <strong>Task page</strong> tab.
2. Enable or disable <strong>Show task scroll</strong> to control automatic scrolling.
3. Adjust subtask depth dots to change how many subtasks appear expanded by default.
4. Use <strong>Expand inline details</strong> to show or hide extra metadata on cards.
5. Save your changes.

## Keyboard Shortcuts

For quick navigation within Profile:

| Shortcut | Action |
|----------|--------|
| Ctrl+K then type "Profile" | Open the full Profile page |
| Ctrl+K then type "General" | Jump to General tab |
| Ctrl+K then type "Appearance" | Jump to Appearance tab |
| Ctrl+K then type "Task" | Jump to Task page tab |
