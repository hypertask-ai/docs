A single <a href="https://docs.hypertask.ai/connect-an-agent/">connect-an-agent</a> hub page now guides users from creating an agent to connecting it with the CLI or MCP. This page first appeared in the docs menu and docs.hypertask.ai/llms.txt now lists it as the primary connection guide.

## What changed

- **New hub page:** Users can now navigate to a dedicated connector page from the sidebar and llms.txt.
- **Connection path clarity:** The page collects create, configure, and connect steps.

## How it works

The connect-an-agent page provides a consistent onboarding flow, ensuring new users and agents always know how to set up connections from scratch without piecing together multiple sections. llms.txt points to this hub and lists it first among MCP-related instructions.
