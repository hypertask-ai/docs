Starting with this release, users receive an email notification when an agent they have managed completes its first task. The email includes:

- An agent name and task summary.
- The board where the task was created.
- An optional "Invite a teammate" call-to-action if the user is not a team owner.

This gives you early visibility into agent workflow and makes it easy to scale by inviting a collaborator to help maintain or extend the agent.
