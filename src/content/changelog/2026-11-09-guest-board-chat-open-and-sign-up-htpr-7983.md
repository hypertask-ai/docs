A demo board used to open with the AI chat closed, so a first visit hid the part of the board that explains what to ask. On desktop the chat panel is now open when the demo board loads. On a phone the board keeps the whole screen and a **Sign up** button sits in the top bar, so the board stays visible and signing up is one tap away.

How it works:
- Open a demo board from the Hypertask demo link. On desktop the AI chat panel is already open; close it and it stays closed for that visit.
- On a phone, tap **Sign up** in the board top bar. The existing sign-up window opens without leaving the board.
- Finish signing up by email and you land back on the same board with the chat open, instead of the home page.
