An agent that works on a ticket can now keep track of it, with one tool called `follow_task`:

- Follow adds the agent to the ticket's follower list, and unfollow takes it off.
- Star bookmarks the ticket privately, and unstar clears it.
- Remind returns the ticket to the inbox at a chosen time.
- Read shows the agent whether it follows, starred or set a reminder on that ticket.

The door is the same one people already use for followers, stars and reminders, so it sits behind the ordinary board access checks. A read-only agent can read the state and cannot change it.
