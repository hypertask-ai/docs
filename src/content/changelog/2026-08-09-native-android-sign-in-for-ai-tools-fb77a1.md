Android AI Chat streaming and Task Writer accept native OAuth tokens, while web cookies remain the first choice.

## Details

Added: Android AI authentication now accepts native user OAuth tokens for AI chat streaming and AI-assisted Task Writer, extending the PKCE OAuth 2.1 flow to the Android app while keeping web cookies as the first priority (HTPR-5225)
