An agent that needs a board it cannot reach no longer stalls with a refusal only. It can ask:

- The agent sends an access request with the board and a short reason.
- The owner gets it in Inbox Decisions and approves or declines in one click.
- Approving adds the agent as a plain member of that board, the same as ticking Board access by hand. No role changes.
- Declining adds nothing and tells the agent.
- A request expires after seven days.

Only the agent's owner can decide, and only for a board in the same team. The agent can read its own request to see the state and the next step.
