title: "Removed Connect your agent block from new board start"
tags: ["Board"]
summary: "On a never-connected new user, the Connect your agent block above board columns is no longer shown on desktop and mobile; the board now opens at the top."
---

On board start with no prior connection, the block that prompted users to connect their agent above the board columns is removed. New users now see their queues and columns immediately, with no distracting prompt. This applies to both desktop and mobile views when starting a board fresh.
