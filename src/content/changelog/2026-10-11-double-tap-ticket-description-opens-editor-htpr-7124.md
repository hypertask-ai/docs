Double-tapping the text of a ticket description on mobile now opens the editor instead of staying in read mode. Previously, tapping on the description text did nothing on phone screens; users had to use the edit controls instead. The update preserves the existing behavior for single taps (read mode) and hover icons, so only double taps on plain description text trigger edit mode. This change was verified on the live site for both plain descriptions and descriptions with formatting like bold text.
