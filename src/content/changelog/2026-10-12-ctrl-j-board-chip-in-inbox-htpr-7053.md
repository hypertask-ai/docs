Ctrl+J now shows a board chip in the inbox, making it clear which board a newly created task will land in. The chip appears next to the task row, similar to the AI chat box, and lets you change the target board before saving the task. When the open board is obvious, the chip stays hidden so the display remains clean. This applies when starting tasks via the inbox: if a task is focused, Ctrl+J uses that task's board; otherwise it uses the open board split, or All/Important board, the last used board.

This utility refines how keyboard-primed workflow entry interacts with board-agnostic views, giving you instant visual confirmation of your board decision.
