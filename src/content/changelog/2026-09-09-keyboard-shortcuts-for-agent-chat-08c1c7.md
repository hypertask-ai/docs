Agent Chat adds shortcuts for switching agents, searching tasks, sending messages, opening links, and focusing input. Agent bubbles use the theme's primary color.

## Details

Added Agent Chat keyboard shortcuts: cycle agents with ctrl+Tab/shft+ctrl+Tab, search tasks with @, add agents with +, send with ctrl+Enter, open links with ctrl+O, and focus the input with ctrl+Q. Agent bubbles now use the theme's primary color (HTPR-6033)
