An optional rail icon opens running timers on boards with active tracking. Alt+T starts or stops a task timer.

## Details

Added rail-accessible timer controls - an optional Rail Timer icon on boards with active time tracks toggles the running-timers page, and Alt+T starts/stops a timer directly on a task (HTPR-4415)
