tags: ["AI","Agents","CLI"]
summary: "Teams without an AI key now see a clear message instead of server errors when using AI in agents or the CLI."
---

Before this fix, teams without an AI key would encounter server errors when trying to use AI-powered features, including agents and the Hypertask CLI. As of October 8, 2026, they now receive a clear guidance message directing them to configure an AI key in Appearance & AI Models.
