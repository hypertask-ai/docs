New users and those installing Hypertask from the web app now see a consistent CLI install approach across all onboarding surfaces. Settings &gt; Connect &gt; CLI shows the curl install script plus `hypertask login` instructions and a platform-specific snippet for Windows (tested across desktop and mobile, and across themes). Both brand-new and returning users receive identical commands, reducing confusion about how to set up the CLI.
