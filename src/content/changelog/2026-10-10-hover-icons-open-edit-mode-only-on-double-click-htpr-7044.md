tags: ["Tasks"]
summary: "Hover icons on comments and descriptions now require double-click for edit mode to open."
---

The emoji button, reaction, menu, and other hover icons on comments and descriptions previously responded to single clicks by entering edit mode. This has been corrected so that a single click on these icons preserves the editor state, and a double-click is required to enter edit mode. This change applies across all four light/dark themes and ensures quick access to actions without accidentally opening the task field for editing.[HTML: tech-fl aws removed]
