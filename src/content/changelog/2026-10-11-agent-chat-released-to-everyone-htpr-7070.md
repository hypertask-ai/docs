Agent Chat flags have been released to Everyone instead of temporarily hiding Agent Chat for all but board owners. The earlier plan to gate Agent Chat behind a visibility flag was superseded by opening the feature to all users without restrictions. No other behavior changes are documented. 

This decision aligns with the broader rollout of AI-powered interactions across Hypertask, ensuring all users can access AI assistants directly from tickets and boards.
