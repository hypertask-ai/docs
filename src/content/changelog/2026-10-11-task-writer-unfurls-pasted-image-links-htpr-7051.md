The AI Task Writer now unfurls pasted image links so they display as images instead of plain text links.

When you paste an image URL (that resolves to an image) into a draft, the system now renders the image inline rather than showing only the link. This works in both the New Task flow and the text editor, across desktop and mobile, and in all theme variants.

On mobile, this means the AI Task Writer will show the embedded image alongside the generated task content if you include an image link in your prompt.

Previously, pasted image URLs were kept as plain text. Now the AI assistant identifies them and displays the full image, making it easier to see the visual context before saving.
