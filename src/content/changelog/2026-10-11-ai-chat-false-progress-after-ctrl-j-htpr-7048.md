After creating a task with **Ctrl+J**, the AI chat previously displayed a false “another reply is in progress” notification, blocking immediate follow‑up questions. This release fixes the state so the chat correctly reflects task‑creation status. You can now fire prompts right after generating a ticket without the confusing timing message.

[HTPR-7048](https://app.hypertask.ai/detail/project-15/7048)
