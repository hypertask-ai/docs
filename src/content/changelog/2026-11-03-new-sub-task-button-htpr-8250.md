summary: "Creating a sub-task no longer needs a name that matches nothing. A New sub-task button sits under the search box and opens the usual create window with the parent task already attached."
---

The sub-task window used to hide task creation behind an empty search: you got a create option only after typing a name that matched no existing task. Now a **New sub-task** button stays visible under the search box.

How it works:
- Open a task, then the **Subtasks** section, and start adding a sub-task.
- Click **New sub-task** to open the normal create window with the parent task, the column and any search text you already typed carried over.
- Searching, linking an existing task, and Enter-to-create-when-nothing-matches work as before.
