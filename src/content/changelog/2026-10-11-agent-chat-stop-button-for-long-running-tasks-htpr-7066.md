---

A Stop button now appears in Agent Chat while agents work, letting users stop long-running tasks. When you send a second message while an agent is still working, it appears queued. Pressing Stop cancels the ongoing work and clears queued messages with a "Run stopped" status. The feature is available on desktop and mobile.
