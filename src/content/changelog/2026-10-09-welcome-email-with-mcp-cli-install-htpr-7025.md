Starting with this release, new users creating an account via email receive a welcome email immediately after their first sign-in. The email contains:

- A body title: <strong>Your board is ready. Connect Claude Code in 30 seconds.</strong>
- A CLI install command for Claude Code using the Project 15 documentation CLI install.
- A Cursor setup snippet named "Cursor project: Project 15".
- A pointer to the latest Project 15 documentation CLI reference.

This matches the default behavior for Google signups, ensuring all new users get the same onboarding path and can set up MCP quickly and reliably before using the board.
