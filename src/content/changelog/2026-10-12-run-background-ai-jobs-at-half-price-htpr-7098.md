Background smart-label classification runs that involve many tasks are now routed to Anthropic’s Batch API at half price instead of running sequentially. This brings predictable, cost-efficient processing for large workloads while keeping matching tasks autonomously labeled.

- Matching tasks automatically receive their labels without user action.
- AI activity is logged in each task’s activity feed.
- Background routing replaces the earlier sequential path; you see the same result at lower cost.
