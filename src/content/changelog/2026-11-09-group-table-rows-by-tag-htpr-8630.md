---

Table view used to group rows by board column only. Seeing the whole backlog by topic meant keeping one saved view per tag.

Now table view has a **Group** control with two choices, **Column** and **Tag**. Tag mode shows one foldable group per label, with the number of tickets in its header. A ticket with two tags appears under both. Tickets with no tag sit in a **No tag** group at the end. Filters still apply, so a Status Backlog filter plus Group by Tag shows the backlog split by topic.

The choice saves with the view, so it comes back the way you left it.
