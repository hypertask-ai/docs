The Share Task window teaches its own shortcuts. Hover any of its four options and a tooltip names that option's keys.

- Private title and link: <kbd>Ctrl</kbd> + <kbd>;</kbd> (<kbd>Cmd</kbd> + <kbd>;</kbd> on a Mac)
- Private link only: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>;</kbd>
- Public title and link: <kbd>Ctrl</kbd> + <kbd>.</kbd>
- Public link only: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>

This shortcut list and the new tooltips name the private link keys the same way, so the keys you read are the keys that work.
