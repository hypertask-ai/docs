<Update label="July 19, 2026">
* Improved keyboard shortcuts — <kbd>Ctrl+Q</kbd> now focuses the docked AI chat input on /chat and on boards (when the chat is open) — focus jumps to the input even if the panel is docked or pressed when closed ([HTPR-4416](https://app.hypertask.ai/detail/project-15/4416))
* Added rail-accessible timer controls — an optional Rail Timer icon on boards with active time tracks toggles the running-timers page, and <kbd>Alt+T</kbd> starts/stops a timer directly on a task ([HTPR-4415](https://app.hypertask.ai/detail/project-15/4415))
* Fixed theme readability of staleness age line — on light and paper themes the age line renders in amber-600/red-600 instead of yellow-on-white ([HTPR-4413](https://app.hypertask.ai/detail/project-15/4413))
</Update>
