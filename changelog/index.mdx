## May 29, 2026

### New Features

- **Delete comments from any team member or agent** — You can now delete comments left by other project members, including AI agents. This makes it easy to clean up outdated or agent-generated comments without needing admin intervention. Trust within the team is assumed for collaborative housekeeping. ([HTPR-3666](https://app.hypertask.ai/detail/project-15/3666))

### Bug Fixes

- **Fixed: CLI `task create --description` no longer rejects plain text** — Passing plain text to `--description` now works automatically. The CLI wraps it in `<p>...</p>` before sending to the API, so automation scripts and AI agents don't need to handle HTML formatting manually. ([HTPR-3664](https://app.hypertask.ai/detail/project-15/3664))

## May 14, 2026

### New Features

- **CLI: Sort `task list` results with `--sort-by` and `--sort-order`** — `hypertask task list` now accepts `--sort-by <createdAt|updatedAt|dueDate>` and `--sort-order <asc|desc>`, so you can pull the most recently updated tasks first without post-processing JSON. ([HTPR-3173](https://app.hypertask.ai/detail/project-15/3173))
- **MCP: Reorder board sections programmatically** — the `hypertask_section` tool's `update` action now accepts `move_after_section_id`, so agents can reposition a board's columns without dragging them in the UI. ([HTPR-2987](https://app.hypertask.ai/detail/project-15/2987))

### Bug Fixes

- **Fixed: MCP `hypertask_get_user_context` no longer errors** — The tool threw a TypeError on every call, blocking MCP clients from fetching their user, team, and project context. It now returns the full context as JSON. ([HTPR-3439](https://app.hypertask.ai/detail/project-15/3439))
- **Fixed: MCP `hypertask_inbox_list` returns JSON, not HTML** — `hypertask_inbox_list` was responding with a rendered HTML page instead of structured data, breaking any agent that called it. It now returns proper JSON. ([HTPR-3455](https://app.hypertask.ai/detail/project-15/3455))
- **Fixed: MCP write tools restored** — `hypertask_add_comment_to_task` and `hypertask_attach_files` were failing with internal errors on every call. Both write tools now work correctly. ([HTPR-3660](https://app.hypertask.ai/detail/project-15/3660))
- **Fixed: CLI `comment list` shows comment text** — `hypertask comment list` was returning empty `text` and `commentText` fields for every comment. Comment content now comes through correctly. ([HTPR-3032](https://app.hypertask.ai/detail/project-15/3032))
- **Fixed: CLI `task create` reports the ticket number** — The success output printed the internal database task ID, which was easily confused with the ticket number used in URLs. It now prints `Created task HTPR-XXXX: <title>` along with the task link. ([HTPR-3034](https://app.hypertask.ai/detail/project-15/3034))
- **Fixed: CLI `task list --project` no longer crashes** — `hypertask task list --project <id>` could crash with "Cannot read properties of undefined" partway through paginating results. It now lists tasks cleanly. ([HTPR-3030](https://app.hypertask.ai/detail/project-15/3030))
- **Fixed: Clearer CLI error when `--assignee` gets a non-ID** — Passing a name or email to `hypertask task update --assignee` used to fail with the cryptic `Expected number, received nan`. It now returns `assignee must be a list of integer user IDs`. ([HTPR-3181](https://app.hypertask.ai/detail/project-15/3181))

## April 28, 2026

### New Features

- **CLI: `task update --parent-task` for re-parenting tasks** — You can now change a task's parent directly from the terminal with `hypertask tasks update <ticket> --parent-task <parent-id>`. Pass `--parent-task none` to detach a task from its current parent entirely. Completes the parent-task workflow that was previously only available at creation time via `tasks create --parent-task`. ([HTPR-3264](https://app.hypertask.ai/detail/project-15/3264))

## April 24, 2026

### New Features

- **CLI: Headless login for SSH and CI environments** — `hypertask login --headless` now prints the auth URL to stdout and waits for you to paste the callback URL back into the terminal, completing authentication without a local browser. Auto-detects headless mode when no display server is found — useful for SSH sessions, Docker containers, and CI runners. ([HTPR-3201](https://app.hypertask.ai/detail/project-15/3201))

### Bug Fixes

- **Fixed: CLI `move-board` now correctly moves tasks between projects** — `hypertask tasks move-board <ticket> --target-project <id>` was returning HTTP 404 for all cross-project moves. Tasks can now be moved between projects from the CLI as expected. ([HTPR-3199](https://app.hypertask.ai/detail/project-15/3199))

## April 23, 2026

### Bug Fixes

- **Fixed: CLI `assign` is now idempotent** — Running `hypertask tasks assign <ticket> --user <id>` twice in a row no longer removes the user. The command now ensures the user is assigned regardless of current state, instead of toggling. ([HTPR-3130](https://app.hypertask.ai/detail/project-15/3130))

### Improvements

- **"Save as current view" button label corrected** — The view-saving button was labeled "Save current view" but now reads "Save as current view", accurately reflecting that it saves the current filter/sort configuration as a named view. ([HTPR-3209](https://app.hypertask.ai/detail/project-15/3209))

## April 21, 2026

### New Features

- **AI Chat is now an agentic system** — AI Chat has been upgraded from a conversational assistant to an action-taking agent. It can now create tasks, update properties, assign team members, and manage your board directly from the chat interface — no separate tool call needed. ([HTPR-3543](https://app.hypertask.ai/detail/project-15/3543))
- **MCP and AI Chat can move tickets between boards** — Agents can now move tasks between projects and boards using `hypertask_move_task_between_boards` or by asking AI Chat. This closes the gap between the web command center and agent interfaces. ([HTPR-3590](https://app.hypertask.ai/detail/project-15/3590))
- **CLI: full label management** — The CLI now supports listing project labels and managing labels on tasks. Use `hypertask project labels <project-id>` to browse available labels, and `hypertask task update <ticket> --labels <name>` to add or change labels on existing tasks. ([HTPR-2996](https://app.hypertask.ai/detail/project-15/2996), [HTPR-3029](https://app.hypertask.ai/detail/project-15/3029), [HTPR-3105](https://app.hypertask.ai/detail/project-15/3105))

### Bug Fixes

- **Fixed: Task Writer mobile view rendering** — A rendering discrepancy in the Task Writer's mobile view has been resolved. The accept button and viewport now behave consistently across environments. ([HTPR-3109](https://app.hypertask.ai/detail/project-15/3109))

## April 20, 2026

### New Features

- **AI Chat now available on mobile** — The full AI Chat experience is now accessible on mobile devices. Open AI Chat full-screen to get the same context-aware assistant you have on desktop, wherever you are. ([HTPR-3056](https://app.hypertask.ai/detail/project-15/3056))
- **Task Writer supports Properties during task creation** — You can now set Tags, Task Size, and Priority directly in the Task Writer when creating tasks, bringing AI-generated tasks closer to ready without a follow-up edit. ([HTPR-2969](https://app.hypertask.ai/detail/project-15/2969))
- **CLI: `task move` command** — Move tasks between sections from the terminal with `hypertask task move <ticket> --section <name>`. No web UI needed for board housekeeping. ([HTPR-3658](https://app.hypertask.ai/detail/project-15/3658))
- **CLI: First-run onboarding** — New users running the Hypertask CLI for the first time now get an interactive onboarding guide to authenticate, explore commands, and get productive fast. ([HTPR-3171](https://app.hypertask.ai/detail/project-15/3171))
- **MCP: `due_date` now supported on create and update** — `hypertask_create_task` and `hypertask_update_task` now accept a `due_date` field (ISO 8601), letting agents set deadlines without needing the CLI or web UI. ([HTPR-3646](https://app.hypertask.ai/detail/project-15/3646))
- **MCP: Inbox tools** — Two new MCP tools — `hypertask_inbox_list` and `hypertask_inbox_archive` — let agents read and dismiss inbox notifications programmatically. Useful for building triage and notification-routing workflows. ([HTPR-3625](https://app.hypertask.ai/detail/project-15/3625))
- **Deep link to create a task on a specific board** — Append `?board=<board-id>` to the task creation URL (e.g. `/new?board=inne`) to pre-select a destination board. Useful for bookmarks and integrations. ([HTPR-3578](https://app.hypertask.ai/detail/project-15/3578))
- **Calendar keyboard navigation** — Use a keyboard shortcut to jump forward and backward through calendar periods without reaching for the mouse. ([HTPR-3517](https://app.hypertask.ai/detail/project-15/3517))
- **One-click IDE connect buttons on the MCP page** — The MCP settings page now includes ready-to-use connect buttons for VS Code, Cursor, and other popular IDEs, making it easier to get your agent setup running in minutes. ([HTPR-3546](https://app.hypertask.ai/detail/project-15/3546))

### Improvements

- **Search powered by Typesense** — Task search is now backed by Typesense, delivering faster queries and more accurate results, especially on large boards. ([HTPR-3539](https://app.hypertask.ai/detail/project-15/3539))
- **AI Chat suggested queries use full MCP context** — The quick-action prompts in AI Chat now reflect the full set of available MCP tools, so suggestions are more relevant and actionable for each project. ([HTPR-3653](https://app.hypertask.ai/detail/project-15/3653))
- **CLI: `--created-by` filter for `task list`** — Filter tasks by creator: `hypertask task list --created-by <user-id>`. Removes the need to paginate through all tasks when looking for your own or a colleague's work. ([HTPR-3088](https://app.hypertask.ai/detail/project-15/3088))
- **F2 to edit task titles on Kanban** — Press F2 on a focused task card to edit its title inline, without opening the task detail panel. ([HTPR-3657](https://app.hypertask.ai/detail/project-15/3657))

- **"Following" filter on Calendar view** — Filter the Calendar to show only tasks you're following, matching the filter already available on Kanban. ([HTPR-3581](https://app.hypertask.ai/detail/project-15/3581))
- **Inbox page title shows account name** — The browser tab for the Inbox now displays the relevant section or account name, making it easier to distinguish multiple Hypertask tabs. ([HTPR-3620](https://app.hypertask.ai/detail/project-15/3620))
- **Left sidebar sort improvements** — Projects and sections in the left sidebar now sort more predictably, with refinements to ordering logic based on user feedback. ([HTPR-3580](https://app.hypertask.ai/detail/project-15/3580))
